# PDF Editor

在瀏覽器中執行的 PDF 編輯器，功能參考 Adobe Acrobat。**免登入、免帳號、免 API 金鑰、不需任何認證**；所有處理（包含 OCR）都在本機完成，檔案不會上傳。

## 快速開始

需要 [Node.js](https://nodejs.org/) 18 以上版本。

| 方式 | 指令 |
| --- | --- |
| 一鍵啟動（Windows） | 雙擊 `Start_PDF_Editor.bat`（第一次會自動安裝與建置） |
| 正式版 | `npm install` → `npm run build` → `npm start`（開啟 http://localhost:4173） |
| 開發模式 | `npm install` → `npm run dev`（開啟 http://localhost:5173） |

`npm run setup` 會把執行時需要的資源放進 `public/`：pdf.js 字碼表、OCR 引擎、OCR 語言資料（繁中、簡中、英、日）與思源黑體。只有第一次需要網路，之後可完全離線使用。

## 功能

### 多文件分頁
- 可同時開啟多個 PDF，每個檔案一個分頁（開啟對話框可一次多選，或一次拖放多個檔案）。
- 每個分頁各自保留編輯內容、復原紀錄、縮放比例與捲動位置；有未儲存變更的分頁會顯示圓點。
- 點 × 或用滑鼠中鍵關閉分頁，若有未儲存變更會先詢問；按分頁列的 + 開啟更多檔案。

### 編輯
- **編輯既有文字**：點一下文字行就能直接修改。程式會自動取樣原文字的顏色與背景色，並沿用原本的字級、粗體與位置。儲存時會從 PDF 內容中**真正移除**原文字，所以搜尋或複製只會得到新文字。
- **新增文字**：可選字型、字級、顏色、粗體，也能旋轉。
- **編輯既有圖片**：自動偵測頁面上的圖片，可以移動或縮放、用新圖片取代、匯出成 PNG、複製到剪貼簿或刪除。
- **插入圖片／簽名**：可拖放圖片；簽名可手寫，也能記在瀏覽器裡重複使用。
- **從剪貼簿貼上圖片**：按 Ctrl+V（或工具列的貼上按鈕），剪貼簿中的圖片會直接放到目前頁面中央並自動選取，可立即拖曳或縮放。沒有開啟文件時，貼上的圖片會建立成新的 PDF。
- **快照**（K）：框選頁面上任一區域，放開後自動複製成圖片到剪貼簿（包含編輯內容與註解），也可下載為 PNG，或在頁面上貼成可移動的圖片。
- **註解**：螢光筆、矩形、橢圓、直線／箭頭、手繪。
- **白色塗改**：輸出時會一併移除底下的文字。
- **橡皮擦**（X）：點一下或拖曳經過即可刪除新增的物件（文字、圖片、圖形、螢光筆、簽名）以及 PDF 原有的圖片；手繪線條只擦掉經過的部分。
- 復原／重做（Ctrl+Z／Ctrl+Y），所有物件都能再選取、移動、縮放或刪除。

### OCR 文字辨識
- 使用 Tesseract（WebAssembly）在本機辨識，支援繁體中文、簡體中文、英文、日文。
- 辨識後會加入隱藏文字層，PDF 就能搜尋與複製。
- 辨識出的文字可以直接用「編輯文字」工具修改，跟一般文字一樣。

### 頁面
- **組織頁面**：拖曳排序、旋轉、刪除、複製頁面、插入空白頁或其他 PDF、擷取所選頁面，也可一次選奇數頁／偶數頁或反轉順序。
- **分割**：可依固定頁數、自訂頁碼範圍、每頁一檔或檔案大小上限分割，結果打包成 ZIP 下載。
- **合併**：多個 PDF 和圖片可依指定順序合併。
- **浮水印、頁碼、頁首／頁尾**。
- **列印**（Ctrl+P）：可選全部、目前頁或指定頁碼，可選擇是否包含編輯內容與註解。預設以瀏覽器的 PDF 列印（向量品質）；若無法列印可改用「影像相容模式」（200 DPI）。

### 轉換
- PDF → **Word (.docx)**，三種模式：
  - **保留版面，可編輯**（預設）：圖片、色塊、表格線放在背景，文字以文字框放回原位置，字型、字級、粗體、顏色和字距都貼近原檔。
  - **流動文字**：重建段落，圖片依位置插入，表格列以定位點對齊，適合大幅改寫。
  - **整頁圖片**：外觀完全相同，但不可編輯。
- PDF → **PNG／JPG**（72–600 DPI）、**純文字**、**HTML**。
- **圖片、Word (.docx)、文字 → PDF**。

## 技術架構

| 用途 | 套件 |
| --- | --- |
| 介面 | React 19 + Vite + TypeScript + zustand |
| 顯示 PDF | pdf.js |
| 寫入 PDF | pdf-lib（加上自製的內容串流文字移除，見 `src/lib/contentEdit.ts`） |
| 中文字型子集化 | HarfBuzz WASM（pdf-lib 內建的子集化會漏掉中文的複合字形） |
| OCR | tesseract.js |
| Word | docx、mammoth |

所有編輯都以「物件」形式保存（`src/types.ts`），儲存時才由 `src/lib/exportPdf.ts` 一次寫入 PDF，所以原始檔在儲存前都不會被改動。

## 已知限制
- Word → PDF 只會轉換文字與段落，不包含原檔的圖片與複雜排版。
- 若文字位在 Form XObject 裡，或使用 Type3 字型，編輯時會以遮蓋方式處理，原文字仍會留在檔案中。
- 加密的 PDF 輸入密碼後可以編輯，但儲存時頁面會改以高解析度影像重建。
